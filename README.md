## 🌟 Fitur Utama

1. **6 Format Motion Archetypes Terintegrasi**:
   - 🎭 **Character Skits (Banter Skit)**: Karakter kartun 2D (Manusia vs AI) berdebat dengan animasi mulut reaktif, kedipan mata, zoom kamera, dan suasana diner neon.
   - 🖊️ **Whiteboard Live Drawing**: Animasi spidol marker menggambar diagram alur secara otomatis di atas papan tulis putih.
   - 👾 **Life as a Game (16-bit Pixel RPG)**: Masalah hidup sehari-hari disajikan layaknya turn-based combat game era SNES dengan bar HP dan dialog 8-bit.
   - 🚨 **Breaking News**: Format siaran darurat TV lengkap dengan running ticker tape di bawah dan screenshot forensik pesan chat WhatsApp.
   - 📊 **Clean Explainer**: Tipografi kinetik, grafik modern yang bergerak naik, dan tahapan langkah bertingkat ala SaaS B2B.
   - 🎞️ **Docu-Story**: Dokumenter sinematik berkecepatan tinggi dengan efek Ken Burns pada arsip foto, film grain vintage, dan audio wavebars.

2. **Word-by-Word Kinetic Captions**:
   - Subtitel animasi per kata (*pop-up*) dengan sinkronisasi timestamp yang presisi dan highlight warna dinamis.

3. **Formula Retensi 0.4 Detik**:
   - Scripting terstruktur: Hook 0.4s pertama, pergantian visual tiap 2-3 detik, dan penutup pemancing debat di komentar (*Comment Magnet*).

4. **Editor Naskah & Beat Interaktif**:
   - Pengguna bebas mengubah baris dialog, memilih emosi karakter (Hyped, Sarcastic, Angry, Chill, Curious), serta mengedit hook penutup.

5. **Pratinjau Vertikal 9:16 dengan Safe-Zone Overlay**:
   - Pratinjau langsung di browser dengan tombol toggle area aman Instagram Reels / TikTok / Shorts.

## 🚀 Menjalankan & Menghentikan Web (Port Khusus: 3788)

Web ini menggunakan **Port 3788** (port khusus yang jarang digunakan dan bebas dari bentrok port umum):

### 1. Menjalankan Web:
Cukup klik ganda atau jalankan di terminal:
```cmd
start_web.bat
```
Atau via PowerShell:
```powershell
.\scripts\start_web.ps1
```
Browser akan otomatis terbuka di **[http://localhost:3788/studio](http://localhost:3788/studio)**.

### 2. Menghentikan Web:
Cukup klik ganda atau jalankan di terminal:
```cmd
stop_web.bat
```
Atau via PowerShell:
```powershell
.\scripts\stop_web.ps1
```
Seluruh proses web di port 3788 akan dihentikan secara bersih.
