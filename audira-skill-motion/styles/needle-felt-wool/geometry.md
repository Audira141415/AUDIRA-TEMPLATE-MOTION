## 1. Primary Mesh Archetypes
- **Felt hills:** crest function → `Shape` → `ExtrudeGeometry` (depth 0.3–0.35, bevel 0.12 / 0.1, 5 segments) for a stuffed, pillowy edge.
- **Blanket stitches:** instanced capsule bars (r 0.012, length 0.13) tilted to the crest slope + a `TubeGeometry` running thread 0.13 below the crest.
- **Puppet:** unit spheres/cones scaled into body, head, muzzle, ears, tail, feet; each wrapped by `Fuzzy` shells.
- **Yarn:** long `TubeGeometry` strands wound on precessing great circles (balls) or helices (trunk coils).
- **Notions:** cylinders (spool, needles), button disc with four holes and cross-stitch.
