# Quality bar

Seven frames from each reference film (downscaled). Use them to judge whether a new film's
look-dev and preview are in the same quality class — never to copy their stories, characters,
products or layouts. `worldforge.jpg` = Mars, `worldforge-roma.jpg` = Rome, `paperworld.jpg` is from a
540×960 preview. These stills are the author's original renders and are included only as references.
